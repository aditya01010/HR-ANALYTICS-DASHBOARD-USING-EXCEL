# HR Analytics Dashboard

This project focuses on analyzing Human Resource (HR) data using Microsoft Excel to understand employee demographics, workforce distribution, employee attrition, job satisfaction, and organizational performance.

The project uses Excel's data analysis capabilities, including Pivot Tables, Pivot Charts, and interactive visualizations, to transform raw employee data into meaningful HR insights.

### Key Analysis Areas

- **Employee Analysis:** Total employee count, average age, and workforce distribution.
- **Attrition Analysis:** Employee attrition trends across different age groups, departments, and job roles.
- **Department Analysis:** Employee distribution and attrition across Human Resources, Sales, and Research & Development.
- **Job Satisfaction Analysis:** Employee job satisfaction across different departments.
- **Age Group Analysis:** Workforce distribution across different age categories.
- **Education Analysis:** Employee distribution and attrition based on educational backgrounds.
- **Salary Analysis:** Average monthly income, daily rate, and monthly rate metrics.

### Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Interactive Dashboards

### Project Objective

To transform raw HR data into meaningful visual insights that help understand workforce patterns, identify employee attrition trends, evaluate job satisfaction, and support data-driven human resource management decisions.
